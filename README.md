A tiny Python program that writes one line to `/output/entry.txt`: an alien tourist's review of planet Earth, at most 200 characters, written like a real travel review -- check-in, pros and cons, an overall score and a would-return verdict. The line was picked by drafting twelve candidates and duelling them pairwise on the bounty judge's own criteria -- whether it reads like a real review first, then funniness, originality, and how tight the writing is; three drafts fell at the gate for breaking the 200-character limit. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
